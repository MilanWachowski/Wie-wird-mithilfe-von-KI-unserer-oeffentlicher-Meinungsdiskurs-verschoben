# Wie-wird-mithilfe-von-KI-unserer-öffentlicher-Meinungsdiskurs-verschoben-
 Repository für ein Schulprojekt der 10. Klasse der St. Johannis Schule Bremen zum Thema, wie KI den öffentlichen Meinungsdiskurs beeinflussen kann. Es geht darum, wie Personen oder Gruppen (z. B. Parteien)  die öffentliche Meinung und damit die Politik steuern können. Als erste Inspiration diente ein YouTube Video von Quarks Dimension Ralph zu diesem Thema (in den Quellen verlinkt).
