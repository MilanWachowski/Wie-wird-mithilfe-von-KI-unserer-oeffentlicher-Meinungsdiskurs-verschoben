# Wie-wird-mithilfe-von-KI-unserer-öffentlicher-Meinungsdiskurs-verschoben-
   Repository für ein Schulprojekt (10. Klasse, St. Johannis Bremen) zum Thema: Wie KI den öffentlichen Meinungsdiskurs verschieben kann und wie Personen/Gruppen (z.B. Parteien) damit die öffentliche Meinung und Politik beeinflussen.
